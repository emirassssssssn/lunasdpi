# Lua API docs

GitHub dosya görünümü bu siteyi çalıştırmaz. Yayınlanan belge:

**https://emirassssssssn.github.io/lunasdpi/**

Kaynak: `index.html` + `assets/api.js` (sınıflar ve rehberler) + `assets/app.js` (tema, arama, kenar çubuğu). Yerelde açmak için `index.html` dosyasını tarayıcıya sürükleyin.

Rehberler: Welcome, api_level 2, SDK types, **Build your own system** (`#kit`), **Invent a system** (`#forge`), Packages, sandbox. `api.js` içindeki `guides` ve `classes` dizileri siteyi üretir — yeni tip ekleyince buraya da yazın.
