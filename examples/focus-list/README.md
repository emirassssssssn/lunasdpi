# Focus list

Example Lunas DPI plugin. Zip **this folder** (so `manifest.json` is at the archive root, or inside one top-level folder) and import it from **Settings → Plugins**.

```
focus-list/
  manifest.json
  main.lua
  settings.lua
  modules/domains.lua
  locale/en.json
  locale/tr.json
  assets/icon.svg
  README.md
```

After import, open the plugin, enable it (this grants storage, settings UI, plugin-owned rules, and notifications), then use **Open plugin settings** to edit the domain list.
